# JohnnyCodeur Tech — Site vitrine

Site vitrine responsive en français pour présenter les services et projets JohnnyCodeur Tech.

## Fichiers
- `index.html` : contenu du site.
- `style.css` : design responsive orange/noir.
- `script.js` : menu mobile et année automatique.
- `formulaire.html` : formulaire de demande de projet relié aux boutons « Commander un projet ».
- `images/` : image utilisée dans l'en-tête du formulaire.

## Mise en route
1. Décompressez l'archive.
2. Ouvrez le dossier dans VS Code.
3. Ouvrez `index.html` dans un navigateur ou utilisez Live Server.
4. Testez tous les boutons, les liens et le formulaire sur téléphone et ordinateur.

## Déploiement Netlify
Importez uniquement ce dossier dans Netlify ou déployez ses fichiers. La page vitrine est `index.html` et le formulaire est accessible via `formulaire.html`. Pour que le formulaire Netlify fonctionne, vérifiez sa détection après le déploiement et configurez les notifications par e-mail dans les paramètres Netlify.
